# Анти-ИИ Квен Академия — Химия ГВЭ-9 2027

Бесплатный офлайн-тренажёр для подготовки к ГВЭ-9 по химии в 2027 году. Один HTML-файл, работает без интернета, не требует установки. Прогресс чек-листа и изученных тем сохраняется в браузере.

## Возможности

- **13 заданий письменной части** по официальным проектам ФИПИ 2027:
  - Часть 1 (задания 1–10): один верный ответ.
  - Часть 2 (задания 11–12): множественный выбор и установление соответствия.
  - Задание 13: развёрнутое решение расчётной задачи.
- **Устная форма:** билеты с теорией (до 4 баллов) и задачей (до 3 баллов), критерии оценивания.
- **Справочник:** критерии письменной и устной частей, шкала перевода, что разрешено на экзамене.
- **Чек-лист подготовки** и **план на 25 дней**.
- **Таймер экзамена** (150 минут / 60 минут).
- **Тёмная и светлая темы**, русский и английский интерфейс.
- **Фильтры** по частям работы.

## Технологии

- Чистый HTML + CSS + JavaScript (без фреймворков и зависимостей).
- Адаптивная вёрстка, `localStorage` для сохранения прогресса.

## Как использовать

1. Скачайте `index.html`.
2. Откройте в любом современном браузере.
3. Занимайтесь онлайн или офлайн.
